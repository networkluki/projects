## bitosx.se - Advanced Password Manager
BitosX is a security-focused password manager built around zero-knowledge encryption and strong separation between account authentication and vault encryption.
Vault data is encrypted locally before it reaches the server, so the backend never needs access to the user's master password, raw encryption keys, or decrypted passwords.

The project focuses on secure authentication, encrypted synchronization, session management, key rotation, cross-platform support, and privacy-first infrastructure.
Security is part of the architecture from the first line of code.
