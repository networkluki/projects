## bitosx.se - Advanced Password Manager
BitosX is a security-focused password manager designed around zero-knowledge encryption and strong separation between account authentication and vault encryption.
Vault data is encrypted locally using modern cryptography before it ever reaches the server, meaning the backend never needs access to the user's master password, raw encryption keys, or decrypted passwords.
The platform is being developed with secure authentication, encrypted synchronization, session management, key rotation, cross-platform support, and privacy-first infrastructure.
The goal is simple: build a password manager where security is part of the architecture from the first line of code.
